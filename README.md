# NizamLens

> A creative space for photography, design, experiments, and tools.

**NizamLens** is a personal creative project by **Teuku Muhammad Nizam**, combining photography, visual design, web development, and experimental tools into one place.

The project is built around one simple idea:

**Create. Experiment. Document.**

---

## ✦ What's inside

### Photography

A collection of photographs exploring:

* Nature & landscapes
* Architecture
* Light & atmosphere
* Everyday moments
* Cinematic compositions

### Design

Visual experiments ranging from:

* Brand identity
* Graphic design
* UI design
* Typography
* Digital artwork

### Experiments

Projects created while exploring different technologies and creative workflows.

Some of them include:

* **NizamLens Culler** — an experimental photo culling tool
* **Oryn** — a frontend component marketplace
* **Auto Feeder** — an IoT automation project

---

## ⚙️ Tech

The NizamLens website is built with:

* React
* TypeScript
* Vite
* CSS
* React Icons

The project is intentionally kept lightweight and modular.

## 🛠 Development

Clone the repository:

```bash
git clone https://github.com/N1Z4AMM/NizamLens.git
cd NizamLens
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
